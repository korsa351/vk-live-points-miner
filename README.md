# VK Live Points Miner

Майнер баллов VK Live с публичной панелью статистики.

## Подготовка на сервере

В каталоге проекта подготовьте два файла.

1. **`config.json`** в корне проекта, рядом с `docker-compose.yml`. Возьмите за основу `config.example.json`. В `streamers` укажите имена каналов из адресов VK Live и приоритеты. Меньшее число означает более высокий приоритет.
2. **`cookies/session.json`** по образцу `session.example.json`. Храните файл на сервере в закрытом каталоге.

Например, для каналов `https://live.vkvideo.ru/streamer1` и `https://live.vkvideo.ru/streamer2` укажите в `config.json`:

```json
{
  "streamers": [
    {"slug": "streamer1", "priority": 1},
    {"slug": "streamer2", "priority": 2}
  ]
}
```

Замените `streamer1` и `streamer2` именами своих каналов.

| Поле | Значение |
| --- | --- |
| `access_token` | `accessToken` из декодированного JSON cookie `auth` |
| `refresh_token` | `refreshToken` из того же JSON |
| `expires_at` | `expiresAt`, целое число в миллисекундах Unix |
| `client_id` | Значение cookie `_clientId` |
| `user_agent` | User-Agent браузера, можно оставить пустым |

Cookies своего аккаунта видны в DevTools на сайте VK Live во вкладке **Application → Cookies**. Майнер обновляет `cookies/session.json` при обновлении токенов. Ранее сохранённые сессии можно использовать в том же каталоге.

## Запуск

Из каталога проекта выполните одну команду:

```bash
docker compose up -d --build
```

Откройте `http://<IP-сервера>:8080/`. Для доступа из интернета порт TCP 8080 должен быть доступен в сети сервера.

Панель показывает список каналов, число зрителей, баллы и время просмотра за текущий запуск. Она работает в режиме чтения. Каналы и приоритеты меняются в корневом `config.json`. После правок выполните `docker compose up -d --force-recreate`, чтобы контейнер заново смонтировал файл.

Служебные сообщения доступны через `docker compose logs -f` и в `logs/miner.log`. Если файла сессии пока нет, панель запускается и майнер ждёт его появления.

После авторизации майнер проверяет доступные сундуки на всех настроенных каналах, включая офлайн-каналы. Затем он повторяет проверку раз в минуту. Интервал в секундах можно изменить через `settings.bonus_poll_interval`. Новые события о сундуках также обрабатываются через WebSocket.

Майнер ставит лайк каждой трансляции, которую берёт в активный слот. Он пропускает трансляции, уже отмеченные аккаунтом, и повторяет попытку при следующей проверке активного слота, если VK вернул ошибку. Для отключения установите `settings.auto_like` в `false`.

## Тесты

Локально с Python 3.11 или новее:

```bash
python -m pip install -r requirements.txt pytest
python -m pytest -q
```
